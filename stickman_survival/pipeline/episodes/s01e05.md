# 1203호 5화 — DAY 9: 냉동실의 비밀 (B 갈래, 다시 만든 판)

## 왜 다시 만들었나
10/31 자동 실행본은 "정전 9일째에 냉동실이 이제 녹기 시작하고, 얼음 알갱이가 있으면 다시 얼려도 된다"는 전제였다. 1화에서 세운 규칙(냉동실 48시간)과 어긋나고, 전기가 없는데 다시 얼릴 수도 없다. 휴대폰도 설명 없이 7%로 켜져 있었다. 사용자가 "맥락 없이 튀어나오는 이야기"라고 지적해 11/1에 같은 투표(B)로 다시 썼다. 이 판부터 `SERIES.md`의 스토리 바이블과 RUNBOOK의 이어쓰기 검사를 적용한다.

## 줄거리
통조림 두 개 남음(원인) → 첫날 이후 처음 연 냉동실은 녹은 지 오래 → 여러분의 선택 B, 얼린 생수와 아이스박스, 그런데 민수 집엔 얼린 생수가 없음 → 물렁한 닭고기를 킁킁 "냄새는 멀쩡한데?" → 할머니: 녹고 있는 게 아니라 녹은 지 일주일, 냉동실은 이틀이면 끝, 냄새 멀쩡해도 버려(탈 나는 균은 냄새가 안 남) → 할머니의 B: 첫날 얼린 생수랑 고기를 아이스박스로 옮겨 이틀 더 먹었다, 평소에 빈칸은 얼린 생수로(꽉 차면 이틀, 반이면 하루) → 복습: 민수가 4화 봉투 두 겹으로 꽉 묶어 뚜껑 통에, 할머니가 처음으로 끄덕임 → 생존 점수 72 → 휴대폰은 사흘째부터 꺼 두고 정오에 한 번만 켰는데 7%, 재난문자(전기 복구 일정 미정)를 읽다 0% → A 지하주차장 차에서 충전 / B 1층 공용 충전 줄 → 다음 화 DAY 10 충전 대작전

## 이어쓰기 검사 (RUNBOOK ①)
1. 원인: 통조림 두 개 → 먹을 걸 찾아 냉동실을 엶. 4화 마지막 "냉동실이 녹고 있어요"는 민수의 착각으로 처리("녹은 지 일주일이야"). ✔
2. 확정된 사실: 1화 냉동실 48시간과 일치(녹은 지 오래). 다시 얼리기·온도계 4도 같은 전기 있는 상황의 지식은 뺌. ✔
3. 배터리: 4화 8% → 9일째 7%, 그 이유(꺼 두고 하루 한 번)가 대사에 나옴. 재난문자 읽다 0%, 배지도 0%. ✔
4. 자원: 냉동 음식 전부 버림, 통조림 2개 → 상태 표에 반영, 8화 식량 위기의 씨앗. ✔
5. 복습 컷: 4화 봉투 두 겹·꽉 묶기를 민수가 스스로 함. ✔
6. 지식이 지금 가능한가: 버리기·봉투 처리는 지금 가능. 얼린 생수 채우기는 "평소에" 할 일로 분명히 말함. ✔
7. A/B: 차는 지하주차장에 있고(바이블), 1층 공용 충전대는 비상발전기로 돈다. 둘 다 득실 있음(A 빠르지만 일산화탄소 / B 느리지만 안전·정보). ✔
