## 갈래
13화 A/B: A 집에 머문다 / B 지하 대피소. 결과 없음 → A. A가 이야기상 나은 이유: 1화에서 "이 사이렌이 무슨 뜻인지"를 배워야 2화부터의 행동이 설명된다. B(대피소)는 2~4화에서 공습경보 때 쓴다.

## 줄거리
사이렌 40초, 민수는 창가(13화 마지막 컷 재사용) → 민수의 선택 A, 집에 머묾 → 폰엔 소문("훈련이래, 오발령이래") → 실수: 거실 불 다 켜고 창문 활짝 열어 하늘 구경 → 할머니가 가방 메고 라디오 들고 문 두드림, "불 꺼. 창문 닫고." → 지식: 평탄한 1분 = 경계경보(준비), 물결치듯 오르내리면 = 공습경보(바로 지하) → 복습(시즌 1 7화): 소문 대신 재난문자 "경계경보 발령, 대피 준비" → 경계경보의 할 일: 아이·노인부터 대피 준비, 불 날 것 치우기, 밤엔 불빛 안 새게 → 민수는 불 끄고 안쪽 벽에 앉아 라디오를 켬 "오늘 밤 할 수 있는 건 듣는 것" → 준비 점수 40 → 새벽 4시 경계경보 해제 → A 할머니처럼 가방을 싼다 / B 평소대로 출근한다 → 예고: DAY 1, 아무 일 없다는 듯한 아침
