# 1203호 S2 3화 — 사이렌 3일째: 엘리베이터 대신 계단

11/11 제작. 2화 투표 결과가 비어 있어 **민수의 선택 A(할머니를 먼저 모시러 간다)**, 노션 갈래 `투표 없음`. 목소리 Gideon(ko 10 / en 5), 배속 ko 1.2 / en 1.4, scene_gap 0.4.

## 훅

## 갈래
2화 A/B: A 할머니를 먼저 모시러 간다 / B 먼저 지하로 내려가 자리를 잡는다. 결과 없음 → A. A가 이야기상 나은 이유: 할머니와 함께 내려가야 "엘리베이터 대신 계단"과 "노약자 먼저"가 한 장면에서 나온다.

## 줄거리
DAY 3 밤, 오르내리는 사이렌(공습경보, 1화 복습) → 민수의 선택 A, 현관 옆 가방을 메고 1204호로 → 할머니는 이미 신발을 신고 서 있음, "가스는 잠갔니?" → 민수가 돌아가 가스 밸브·전원 차단 → 12층, 할머니 다리를 생각해 엘리베이터 버튼(실수) → 할머니가 지팡이로 계단 문을 가리킴(전기가 끊기면 멈춤) → 가방 둘은 민수, 난간은 할머니, 이웃이 벽 쪽으로 붙어 길을 내줌 → 지하 2층 주차장, 라디오 → 오늘 할 일: 우리 집 비상계단 한 번 걸어 내려가 보기 → 준비 점수 65 → A 차 안에서 밤을 보낸다 / B 사람들 곁 바닥에 앉는다 → 예고: 대피소의 첫 밤(4화, DAY 3).

## 이어쓰기 검사
1. 원인: 2화 예고·투표 질문("사이렌 3일째 밤, 오르내리는 소리")에서 그대로 시작. ✔
2. 확정된 사실: 가방은 현관 옆(2화), 할머니는 가방을 싸 둠(1화), 차는 지하주차장(상태 표). ✔
3. 배터리: 100% 유지, 전기 있음(엘리베이터가 아직 움직이는 상태라 민수가 버튼을 누름). ✔
4. 자원: 가방 2개를 들고 내려옴. 집 가스·전원 차단. 줄어든 자원 없음. ✔
5. 복습: 1화 "오르내리는 사이렌 = 공습경보, 바로 지하". ✔
6. 지식이 지금 가능한가: 계단 이용, 가스·전원 차단, 라디오 청취 모두 가능. ✔
7. A/B: 차 안(사생활·따뜻함 / 혼자·안내를 못 들음) vs 사람들 곁 바닥(불편 / 안내·도움). 둘 다 그럴 수 있는 선택. ✔
