# 1203호 2화 — DAY 3: 마트 앞의 줄

## 1화 반응을 보고 바꾼 점
- 한국어 계정 조회수 약 1,500, 스킵률 약 50%. 첫 1초에 갈등이 보이도록 바꿨다: 첫 컷부터 끝없는 마트 줄 + 큰 문구 "DAY 3 | 마트 앞 줄", 첫 대사 전 정적을 0.3→0.2초로, 장면 사이 간격도 0.35→0.3초로 줄였다.
- 3장면 만에 "맨 앞엔 할머니" 반전을 둬서 초반 이탈을 막는다.

## 줄거리
정전 사흘째, 마트 앞 끝없는 줄 맨 끝에 민수, 맨 앞엔 할머니 → (지난 화 투표 반영) → 두 시간 만에 차례, 민수는 라면 열 봉지 → 잠깐! 물도 끊겼고 인덕션은 전기, 라면은 짜서 갈증 → 할머니 장바구니: 생수·통조림·크래커·수동 캔따개 → 비상식량은 조리 없이, 물은 1인 하루 약 3L → 민수 집 0L, 현금도 0원 → 할머니가 만 원 건넴, 라면 내려놓고 물·통조림 구입 → 생존 점수 45점 → A/B: 오늘 밤 양초 vs 휴대폰 손전등 → 다음 화 DAY 7, 추워지는 밤

투표 갈래(2장면): A 가족 연락 → 배터리 3% / B 손전등 → 엄마 부재중 스무 통(배터리 12%). 렌더링 때 `--vote A|B`.
