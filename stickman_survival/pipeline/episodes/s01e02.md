## 줄거리 (투표 결과에 따라 갈림)

공통 시작: 정전 사흘째, 마트 앞 줄이 끝이 안 보인다. 맨 앞엔 할머니.

| | A: 가족에게 연락 | B: 밤에 쓸 손전등 |
|---|---|---|
| 줄 위치 | 맨 끝 | 할머니 바로 뒤 (새벽 손전등으로 장 보러 나가는 할머니를 봄) |
| 결과 | 엄마랑 40분 통화 → 배터리 3%, 대신 엄마가 알려준 서랍 속 비상금 5만 원 | 배터리 12%, 엄마 부재중 스무 통 |
| 이 갈래만의 지식 | "통화 말고 문자 한 통" — 문자는 전화가 막혀도 잘 가고 배터리도 아낌 | "신호가 약하면 휴대폰은 신호를 찾느라 배터리를 더 먹는다" → 엄마에게 문자 한 통 보내고 바로 비행기 모드 |
| 계산 | 엄마 비상금으로 당당하게 | 지갑 0원 → 할머니가 만 원 (빚 1만 원) |
| 생존 점수 | 45 | 50 |

공통 중반: 드디어 차례, 라면 열 봉지 → 잠깐! 수도 끊김·인덕션은 전기·짠 음식은 갈증 → 할머니 장바구니(생수·통조림·크래커·수동 캔따개), 비상식량은 조리 없이 → 물 1인 하루 약 3L, 민수 집 0L → 라면 내려놓고 물·통조림 구입

공통 끝: A/B 질문 "해가 졌어요. 오늘 밤 민수는? A 양초를 켠다 / B 할머니네 문을 두드린다" → 다음 화 DAY 7
