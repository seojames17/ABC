# 「1203호」 시리즈 진행 기록

자동 실행되는 세션이 다음 화를 쓰기 전에 읽고, 한 화를 끝낼 때마다 갱신한다.

## 고정 설정

- 무대: 한국 고층 아파트 1203호. 주인공 민수(30대, 빨간 후드, 큰 동그란 안경, 대비 없음, 시청자 대신 실수함)
- 옆집 할머니(1204호): 옛날 정전·물난리를 겪어 본 생존 고수. 말수 적고 늘 한발 앞서 있음
- 톤: 가볍고 웃긴데, 생존 지식은 진짜. 피·잔혹 묘사 금지
- 화면 배지: `1203호 | DAY n` / `UNIT 1203 | DAY n`, 배터리 잔량 표시
- 내레이션: Julian (ko speech_rate 20, en 10)

|---|---|---|---|

## 민수 상태 (투표가 쌓이는 곳)

매화 끝날 때 갱신한다. 다음 화는 이 상태에서 출발한다.

| 항목 | 1화 끝 | 2화 끝 A (안 만듦) | **2화 끝 B (실제)** |
|---|---|---|---|
| 배터리 | 21% | 3% | 12% |
| 현금 | 0원 | 비상금 5만 원(일부 사용) | 0원 |
| 빚 | 없음 | 없음 | 할머니에게 1만 원 |
| 물·식량 | 없음 | 생수·통조림 조금 | 생수·통조림 조금 |
| 가족 | 연락 안 됨 | 통화함 | 걱정 → 문자로 안심 |
| 할머니와 관계 | 비웃음 | 한심해함 | 챙겨줌(빚) |
| 생존 점수 | 30 | 45 | 50 |

## 화별 기록

### 1화 — DAY 1: 곧 들어오겠지 (완료)
- 줄거리: 밤 9시 정전 → 민수는 곧 들어올 거라 방심 → 냉장고 문 열어 냉기 날림 → 할머니는 욕조에 물 받음, 민수는 비웃음 → 다음 날 물 끊김(고층 펌프) → 편의점 카드 불가, 지갑 0원 → 생존 점수 30점
- A/B 질문: 남은 배터리 21%를 A) 가족 연락 B) 밤에 쓸 손전등
- 예고: DAY 3, 마트 앞 줄 (줄 맨 앞엔 할머니, 맨 끝엔 민수)
- 투표 결과: **B** (밤에 쓸 손전등) → 2화 B 갈래로 제작
- 설계도: `episodes/s01e01.json`, 영상: Higgsfield 프로젝트 「1203호 생존툰」

### 2화 — DAY 3: 마트 앞의 줄 (완료, B 갈래)
- 줄거리: 마트 앞 끝없는 줄, 맨 앞 할머니, 바로 뒤 민수(새벽 손전등으로 할머니를 봄) → 엄마 부재중 스무 통 → 할머니: 신호 약하면 배터리 광탈, 문자 한 통 + 비행기 모드 → 라면 열 봉지 실수 → 비상식량·캔따개·물 3L → 지갑 0원, 할머니가 만 원(빚) → 생존 점수 50점
- A/B 질문: 해가 졌다, 오늘 밤 A) 양초를 켠다 B) 할머니네 문을 두드린다
- 예고: DAY 7, 추워지는 밤
- 투표 결과: (사용자에게 받아서 기록)
- 설계도: `episodes/s01e02.json` (`--vote B`), 내레이션 배속 ko 1.12 / en 1.2
- 영상: 한국어 72.8초 media `693e3cf0-3bcb-4d1c-83e0-6ba5e6f083c6`, 영어 media `b2f7627f-6bf6-4d35-99d2-7de043f7bea7` (Higgsfield 「1203호 생존툰」)
- 비용: 실제 26.7크레딧 (그림 25장 재생성 2 포함, 음성 26줄 재녹음 3 포함). 예상(16)보다 많음 → 다음 화부터 예상치를 약 25로 잡을 것
- 제작 메모: 첫 컷에서 군중이 전부 민수 옷을 입고 나옴 → 군중 컷은 민수 시트 말고 1화 101번(마트 줄) 컷을 참고 이미지로. "비행기 모드" 아이콘이 종이비행기(메신저 로고처럼)로 나옴 → "빠른 설정 패널의 비행기 토글"로 지정.
