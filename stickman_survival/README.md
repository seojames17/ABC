# 졸라맨 생존기 — 아포칼립스 생존 스토리텔링

졸라맨 캐릭터가 여러 아포칼립스 상황에서 살아남는 연재형 숏폼(인스타 릴스 / 유튜브 쇼츠).
이야기 속에 **실제 생존 지식**을 섞어, 재미와 정보를 함께 주는 것이 핵심입니다.

## 시리즈 규칙

- **화면 고정 요소**: 왼쪽 위 `DAY n` 카운터, 오른쪽 위 배터리 잔량
- **매화 구조**: 위기 → 민수의 실수 → 진짜 생존 지식 → 생존 점수 → A/B 질문 → 다음 화 예고
- **금지**: 피·잔혹한 묘사, 실존 작품(웹소설·영화) 설정 따라 하기, 지어낸 이야기를 실화라고 하기
- **사실 확인**: 생존 정보는 틀리면 위험하므로 매화 `fact-check` 표를 채우고 올리기 전 확인

## 캐릭터

| 캐릭터 | 설정 | 상징 색 | 기준 시안 (Higgsfield job id) |
|---|---|---|---|
| 민수 | 대비 안 된 평범한 30대. 시청자 대신 실수하는 역할 | 파란 비니 | `546624c1-a751-4fc5-8a12-12075d56279f` |
| 옆집 할머니 | 옛날 정전을 겪어 본 생존 고수 | 주황 숄, 동그란 안경, 쪽머리, 지팡이 | `bb68c721-a169-4192-abe0-b860ac4770cc` |

장면 이미지를 만들 때 위 job id를 `image_references`로 넣으면 캐릭터가 유지됩니다.

## 제작 파이프라인

1. **대본·콘티**: `episodes/sNNeNN.md` 형식으로 작성 (내레이션, 장면, 화면 문구, 사실 확인)
2. **장면 이미지**: Higgsfield `gpt_image_2_5`, 9:16, quality `medium` (장당 0.5크레딧).
   공통 스타일 문구 + 캐릭터 참고 이미지 사용. 한 번에 2~3장씩 보내야 속도 제한(429)에 덜 걸림
3. **내레이션**: Higgsfield `seed_audio`, 목소리 Gideon (`1ad38ba4-9cc4-4f2f-9fde-b0fefdf67ae5`),
   `speech_rate: 20`, 장면별로 따로 생성 (줄당 0.2크레딧).
   숫자·영어는 발음이 흔들리므로 한글로 풀어 쓰기 (예: "4시간쯤" → "네 시간 정도", "DAY 3" → "데이 쓰리")
4. **편집**: 장면 길이 = 내레이션 길이 + 0.4초. 살짝 확대(최대 1.06배), 자막·DAY 카운터·배터리는
   Pillow로 그린 투명 PNG를 겹침. 글꼴: Black Han Sans(강조), Noto Sans KR Bold(자막)
5. **음성 확인**: faster-whisper로 받아 적어 대본과 비교
